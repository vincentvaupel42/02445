You are given a Machine Learning exam consisting of a given number of multiple 
choice questions. Each question has exactly 5 answer options labeled A, B, C, D, E. 
Exactly one option is correct.

Your task: Answer every question. For each question, output only the 
question number followed by your chosen answer.

Output format (exact):

1: <letter>

2: <letter>

3: <letter>

...

27: <letter>

Strict rules:

- Output exactly 27 lines, one per question.

- Each answer must be a single letter from A to E

- Do not output explanations, reasoning, headers, or any other text.

- Do not skip questions. If you are uncertain, choose your best guess.

- Do not output anything before the first line or after the last line.
